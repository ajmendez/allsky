Youtube Uploader

AllSky Youtube Uploader: uploads captures of the sky around the clock, identifies stars and aircraft, builds daily timelapse videos, and publishes them to YouTube.

Hardware Setup

A typical AllSky Youtube Uploader station consists of a few affordable components mounted outdoors with a clear view of the sky:

▩
Raspberry Pi
Pi 4 or Pi 5 recommended. Runs the capture daemon, image processing, and web server.

ZWO ASI (e.g., ASI178MC), Raspberry Pi HQ with fisheye lens, or Arducam. Covers the full 180° hemisphere.

Timelapse Pipeline

AllSky Youtube Uploader runs an automated pipeline that transforms raw sky frames into polished timelapse videos and publishes them to YouTube without manual intervention.

  1. Capture — The camera daemon takes an exposure every few seconds. Daytime uses short exposures (~1 ms); nighttime ramps up to multi-second exposures for maximum star visibility. Gain, white balance, and gamma adjust automatically based on ambient light.
  2. Overlay — Each frame is annotated with a timestamp, constellation lines, identified objects, and camera metadata. Overlays are configurable through the AllSky web UI.
  3. Keogram & Startrails — At the end of each night, a keogram (a single strip showing the sky's evolution over time) and a startrail composite are generated from the night's frames.
  4. Timelapse Encoding — ffmpeg assembles the day's annotated frames into an MP4 video. Typical output is 1–3 minutes at 25 fps, covering the full 24-hour cycle.
  5. YouTube Upload — The finished timelapse is uploaded to your YouTube channel via the YouTube Data API v3. The video title, description, and privacy setting are automatically populated with the date, location, and capture statistics.

Star & Object Detection

Beyond simple imaging, AllSky Youtube Uploader can identify what's in the sky using two complementary approaches:

Astrometric Plate Solving

Each nighttime frame can be plate-solved — the process of matching the pattern of detected point sources against a star catalog to determine the precise sky coordinates of every pixel. This enables:

  • Constellation overlay with star names and magnitudes
  • Planet identification (visible planets labeled in real time)
  • Meteor detection by identifying fast-moving streaks that don't match known objects
  • Cloud coverage estimation based on the ratio of expected vs. detected stars

Aircraft & Satellite Identification

When paired with an ADS-B receiver (an RTL-SDR dongle tuned to 1090 MHz), AllSky Youtube Uploader correlates aircraft transponder data with streaks visible in long-exposure frames:

  • ADS-B aircraft — Flight number, altitude, speed, and aircraft type are matched to visible trails using position and timing
  • Satellites — TLE (Two-Line Element) orbital data from CelesTrak predicts satellite passes; bright streaks at the predicted positions are labeled with satellite names (ISS, Starlink, etc.)
  • Unknown objects — Streaks that match neither known aircraft nor predicted satellite passes are flagged for review

YouTube Integration

AllSky Youtube Uploader uses the YouTube Data API v3 to upload daily timelapse videos to your YouTube channel. This is the primary Google API integration and requires you to authorize the application with your Google account.

The integration uses the following OAuth scope:

  • youtube.upload — Permission to upload videos to your YouTube channel

The application does not read, modify, or delete any existing content on your channel. It only uploads new videos that your AllSky Youtube Uploader has generated. You can revoke access at any time through your Google Account permissions.

Open Source

AllSky Youtube Uploader is free and open-source software, maintained by the AllSky community. The source code is available on GitHub. Contributions, bug reports, and feature requests are welcome.

Getting Started

To set up your own AllSky Youtube Uploader, you need a Raspberry Pi (Pi 4 or newer recommended), a compatible camera with a fisheye lens, and a weatherproof enclosure. Follow the installation guide for detailed instructions on hardware assembly, software installation, and YouTube API configuration.
